⚡ Neuon v0.2 — Architecture

Neuon is a desktop AI automation assistant built in Java 21 with JavaFX. It uses the Groq API for LLM inference, manages conversation memory, and exposes tools for shell execution, file management, and code generation. This document describes the architecture after the v0.2 refactor.

1. Layer Overview

2. Key Components

🔄 AgentLoop new

src/main/java/com/neuon/agent/AgentLoop.java

Shared conversation loop consumed by both OrchesterAgent and CodeAgent. Handles:

  • Building the request body (messages + tools)
  • Calling LLMClient and checking LLMResult
  • Parsing responses with ResponseParser
  • Executing tool calls via ToolRunner
  • Max-step enforcement (default 15)
  • Invalid tool-call detection

📦 LLMResult new

src/main/java/com/neuon/core/LLMResult.java

Structured API response record:

  • boolean ok — success/failure
  • String body — response body (if ok)
  • int statusCode — HTTP status
  • String error — error message (if !ok)

🧠 Memory refactored

src/main/java/com/neuon/core/Memory.java

  • ShortTermMemory — last 6 conversation pairs (capped), thread-safe
  • LongTermMemory — JSON file at ~/.neuon/LongTermMemory.json
  • Auto-skips [ERROR] responses from short-term memory
  • Safe JSON parsing: resets file if corrupt

🛡️ SafetyCheck improved

src/main/java/com/neuon/tools/SafetyCheck.java

  • Extended block list: apt, curl, wget, systemctl, dpkg, yum, dnf
  • Path traversal detection in command arguments (../)
  • Automatic command audit log at ~/.neuon/safety.log
  • Confirmation required for install commands, rm, chmod, etc.

📁 WorkspaceManager new

src/main/java/com/neuon/tools/WorkspaceManager.java

  • Wraps and extends existing WorkspacePaths
  • Safe path resolution, prevents traversal
  • Project creation, file listing, read/write
  • Root: ~/Desktop/workspace or $NEUON_WORKSPACE

🧰 New Tools new

ListFilesTool.java · EditFileTool.java

  • list_files — list directory contents inside workspace
  • edit_file — full content replacement, workspace-safe
  • Both registered for orchestrator and code agent

3. Request Lifecycle

  1. User types a prompt in the JavaFX input field and presses Enter (or clicks FIRE/SPEAK). NeuonFXApp.sendPrompt() starts a background Task<Void>.
  2. OrchesterAgent.getLLMResponse() is called. It loads the system prompt (from PromptOrchester), the tool definitions, and the short-term memory pairs, then delegates to AgentLoop.
  3. AgentLoop.run() builds the message array (system + history + current user), constructs the JSON body via RequestBuilder, and calls LLMClient.ask().
  4. LLMClient sends an HTTP POST to the Groq API endpoint. Returns an LLMResult record (ok + body + status + error). If 429, retries once after Retry-After delay.
  5. ResponseParser parses the JSON body. Three outcomes:
    • stop → return the text content to the user
    • tool_calls → extract each call (name, args, id), execute via ToolRunner → ToolDispatcher → ToolHandler, inject the result back, and loop (up to 15 steps)
    • error → return error text; not added to memory
  6. OrchesterAgent stores the final response in ShortTermMemory (unless it starts with [ERROR]) and returns it to the UI.
  7. If the orchestrator calls invoke_code_agent, the CodeAgent spawns its own AgentLoop instance with its own system prompt, tool set, and memory. It runs autonomously until it responds TASK COMPLETE or hits the step limit.

7. What Changed in v0.2

🔄 Shared Agent Loop new

OrchesterAgent and CodeAgent no longer duplicate the conversation loop. AgentLoop handles request building, LLM calls, parsing, and tool execution.

📦 Structured API Results new

LLMResult replaces raw string returns. Every API call now returns ok/body/statusCode/error. 429 rate limits trigger automatic retry.

🧰 Code Agent Tools new

CodeAgent went from 3 tools to 6: list_files, read_file, edit_file added. Can now inspect existing projects before modifying.

📁 Workspace Service new

WorkspaceManager provides safe path resolution, project creation, file listing, read/write. Env var NEUON_WORKSPACE overrides default ~/Desktop/workspace.

🛡️ Safety Improvements improved

Extended block list, path traversal detection, command audit log at ~/.neuon/safety.log, confirmation for installs.

💻 UI Upgrades improved

Status indicator (IDLE/THINKING/ERROR), model name, API key dot, workspace file list, tool call display, stdout/stderr panels, Cancel + Clear buttons.

🧠 Memory Cleanup improved

STM capped at 6 exchanges. Error responses ([ERROR]) are never stored. Corrupt JSON files auto-reset. Optimizer disabled.

🧪 Test Suite new

27 JUnit 5 tests covering ResponseParser, MessageBuilder, WorkspacePaths, and ToolWareHouse. Run with mvn test.

⚡ Prompt Tightening improved

Shorter operational prompts. Orchestrator told to delegate coding tasks. Code agent gets explicit 5-step workflow. Lower token burn.
